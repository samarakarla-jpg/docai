# DocAI

O DocAI é uma plataforma para criação orientada de documentos contratuais profissionais. Este arquivo é apenas a entrada do projeto; decisões vigentes pertencem às fontes oficiais abaixo.

## Fontes oficiais

| Assunto | Documento oficial |
| --- | --- |
| Arquitetura | [`ARCHITECTURE.md`](ARCHITECTURE.md) |
| Visão, estratégia e funcionalidades do produto | [`PRODUCT_SPEC.md`](PRODUCT_SPEC.md) |
| Evolução e prioridades da biblioteca | [`docs/ROADMAP_BIBLIOTECA.md`](docs/ROADMAP_BIBLIOTECA.md) |
| Desenvolvimento e colaboração | [`AGENTS.md`](AGENTS.md) |
| Interface e acessibilidade | [`UI_GUIDELINES.md`](UI_GUIDELINES.md) |
| Estilo de código | [`CODE_STYLE.md`](CODE_STYLE.md) |
| Trabalho autorizado | Sprint ativa em `docs/SPRINT_NN.md` |

Cada assunto possui uma única fonte oficial. Documentos auxiliares apenas apontam para ela e registros de Sprint representam o contexto histórico de cada entrega.

## Antes de trabalhar no projeto

1. Leia [`AGENTS.md`](AGENTS.md).
2. Identifique e leia a fonte oficial responsável pelo assunto.
3. Leia integralmente a Sprint ativa.
4. Inspecione o estado atual do repositório e preserve alterações preexistentes.
5. Não trate roadmap, histórico ou referência como autorização de implementação.

## Documentos de referência

`AI_RULES.md`, `MASTER_PROMPT.md`, `VISION.md`, `PROJECT_PRINCIPLES.md`, `DEVELOPMENT_WORKFLOW.md`, `ROADMAP.md` e `PROJECT_STATE.md` são mantidos por compatibilidade e direcionam o leitor às fontes oficiais. Eles não redefinem decisões.

## Registros históricos

Os arquivos `docs/SPRINT_NN.md` registram o escopo e as decisões de cada Sprint. Enquanto uma Sprint está ativa, ela delimita o trabalho autorizado. Depois de aprovada e encerrada, torna-se registro histórico e não substitui as fontes oficiais. Sprints legadas mantidas na raiz também são registros históricos.

Planejamentos legados identificados por `D01` a `D07` não definem prioridades vigentes e não autorizam implementação.

## Execução e validação

Comandos, dependências, requisitos de ambiente e critérios de validação devem ser confirmados no repositório e na Sprint ativa. Não instale, remova ou atualize dependências sem autorização explícita.
