# Sprint 02 — Dashboard

## Objetivo

Construir o dashboard definitivo da aplicação após a autenticação.

O usuário deve entrar na aplicação e visualizar um painel organizado, mesmo sem possuir contratos.

---

## Funcionalidades

### Dashboard

Criar um layout protegido contendo:

- Sidebar
- Header
- Área principal

---

### Sidebar

Itens:

- Visão Geral

Na parte inferior:

- Sair

---

### Header

Exibir:

- Nome do usuário autenticado
- E-mail do usuário

---

### Área principal

Título:

Dashboard

Descrição:

Gerencie seus contratos.

Adicionar botão:

Novo contrato

---

### Lista de contratos

Nesta sprint ainda não haverá integração com banco.

Mostrar apenas o estado vazio.

Mensagem:

Você ainda não possui contratos.

Botão:

Criar primeiro contrato

---

## Requisitos

- Utilizar componentes reutilizáveis.
- Layout responsivo.
- Manter autenticação existente.
- Não alterar regras de login.
- Não adicionar IA.
- Não adicionar Stripe.
- Não adicionar geração de contratos.

---

## Critérios de aceite

O sprint será considerado concluído quando:

- O usuário autenticado acessar o dashboard.
- O layout estiver organizado.
- O botão "Sair" funcionar.
- O botão "Novo contrato" existir.
- O estado vazio aparecer corretamente.
- Não houver erros de TypeScript.
- Não houver erros de lint.
