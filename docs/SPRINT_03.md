# Sprint 03 – Seleção do tipo de contrato

## Objetivo

Permitir que o usuário inicie a criação de um contrato.

Ainda não haverá geração por IA.

## Funcionalidades

- Ao clicar em "Novo contrato", abrir a página de criação.
- Exibir quatro opções de contrato:

  - Prestação de Serviços
  - Compra e Venda
  - Aluguel
  - Empréstimo

- Cada opção deve ser apresentada em um card clicável.

- Ao selecionar um tipo, habilitar o botão "Continuar".

- O botão "Continuar" deve levar para a página do formulário correspondente.

## Não implementar

- IA.
- Gemini.
- Geração de PDF.
- Salvamento no banco.
- Upload.
- Histórico.
- Assinatura.

## Critérios de aceite

- Dashboard continua protegido.
- Botão "Novo contrato" funciona.
- Página de seleção abre corretamente.
- É possível selecionar apenas um tipo.
- Botão "Continuar" só habilita após seleção.
- Layout responsivo.
- TypeScript sem erros.
