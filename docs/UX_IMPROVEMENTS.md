# UX Improvements

## Objetivo

Este documento reúne sugestões de melhorias de experiência do usuário (UX) identificadas durante o desenvolvimento e uso do DocAI.

As ideias registradas aqui serão avaliadas e implementadas nas próximas sprints.

---

# Filosofia do Produto

## Princípio do DocAI

O DocAI foi criado para qualquer pessoa que precise criar um contrato, mesmo sem conhecer termos jurídicos.

A interface deve ser simples, intuitiva e acolhedora. Sempre que possível, devemos utilizar uma linguagem fácil de entender.

Os termos jurídicos devem aparecer apenas no contrato final, nunca no formulário, quando houver uma alternativa mais clara para o usuário.

Antes de adicionar qualquer novo campo, funcionalidade ou texto na interface, faça sempre a seguinte pergunta:

> **"Uma pessoa que nunca fez um contrato entenderia isso?"**

Se a resposta for **não**, a interface deve ser simplificada.

Nosso objetivo é que qualquer pessoa consiga criar um contrato profissional em poucos minutos, sem precisar pesquisar o significado de termos jurídicos.

# Melhorias de UX

## Linguagem do formulário

- Alterar **"Objeto do contrato"** para **"Qual é o serviço?"**.
- Adicionar exemplos abaixo do campo.
  - Ex.: pintura de uma casa.
  - Ex.: instalação de ar-condicionado.
  - Ex.: criação de um site.
  - Ex.: consultoria.
  - Ex.: aulas particulares.
- Alterar **"Contratante"** para **"Contratante (seus dados)"**.
- Alterar **"Contratado"** para **"Contratado (dados da pessoa que realizará o serviço)"**.
- Utilizar linguagem simples em todos os formulários.

---

## Contrato

- Adicionar área para assinatura.
- Espaço para assinatura do Contratante.
- Espaço para assinatura do Contratado.
- Campo de data abaixo das assinaturas.
- Melhorar o espaçamento e organização visual do contrato.

---

## Exportação

- Botão para salvar em PDF.
- Botão para baixar em Word.
- Botão para imprimir.
- Utilizar nomes claros para cada ação.

---

## Edição

- Permitir editar os dados do contrato antes da versão final.
- Após a edição, gerar novamente o contrato utilizando IA.
- Atualizar o mesmo contrato em vez de criar um novo.

---

## Financeiro

- Permitir selecionar a moeda (BRL, USD e EUR).
- Exibir automaticamente o símbolo da moeda.
- Formatar valores automaticamente.

---

## Dashboard

- Continuar simplificando a interface.
- Evitar botões duplicados.
- Manter apenas ações realmente necessárias.

# Regra de Ouro

Sempre que surgir uma nova funcionalidade ou alteração na interface, pergunte:

> "Uma pessoa que nunca fez um contrato entenderia isso sem pedir ajuda?"

Se a resposta for "não", a interface deve ser simplificada.

A simplicidade é uma das principais características do DocAI.
